# FinReason 金融数值推理后训练

基于 Qwen3-1.7B，完成 **LoRA SFT → 执行反馈 GRPO → 冻结评测**。模型读取财务表格、上下文与问题，生成受限 FinQA 程序，再由执行器计算答案。

v0.1.0 是已完成 v3 的首个开源版本，提供代码、配置、固定数据 ID、逐题预测与结果核验。v0.1.1 新增五份原始 adapter 的可核验 ZIP，以及经过 GPU 试跑的推理和本地评分入口；详见[权重与小样本复现](docs/ADAPTERS.md)。项目没有 RAG 或 Agent 调度，也不是新提出的强化学习算法。

## 结果

最终评测使用原 FinQA train 中提前按 company/year 分组留出的 551 题、91 个分组，**不是 FinQA 官方 test**，也不是整个项目历史从未接触过的数据。

| 模型 | 正确 | 可执行 | 相对 SFT |
| --- | ---: | ---: | ---: |
| SFT | 388/551，70.42% | 550/551 | — |
| binary GRPO，seed 42 | 397/551，72.05% | 550/551 | +1.63 个百分点 |
| binary GRPO，seed 1234 | 398/551，72.23% | 550/551 | +1.81 个百分点 |
| validity 0.1，seed 42 | 399/551，72.41% | 550/551 | +2.00 个百分点 |
| validity 0.1，seed 1234 | 397/551，72.05% | 550/551 | +1.63 个百分点 |

两个 binary 种子方向一致，但 95% 文档聚类区间分别为 [0.00,3.30] 和 [0.52,3.25] 个百分点，不能写成两个种子均显著。两者共用一次 SFT 起点。有效性奖励相对 binary 多/少正确 +2/−1 题，没有一致优势。全部固定模型完整报告，不按 final 选赢家。

另外，在独立的 407 题开发范围内，基座正确 38 题、SFT 正确 262 题；不能把开发集基座成绩与最终集 RL 成绩直接作差。

## 实验内容

- SFT：3,500 条，FP32 LoRA，r=16、alpha=32，all-linear，875 次更新。
- GRPO：1,000 道问题，每题 8 次采样，两种奖励 × 两个种子，各 1,000 次更新；BF16、beta=0，无动态补采和 vLLM。
- 数据：固定顺序 ID、company/year 分组、保守近似问题排重；输入白名单只放报告、表格和问题。
- 工程：非思考模板对齐、受限 DSL、官方执行器、逐题断点保存、真实优化器更新检查、预测和权重哈希归档。
- 评测：正确率和可执行率分开报告，记录新增正确与退化，按文档聚类抽样 10,000 次估计区间。

## 不需要显卡的检查

```bash
python -m unittest discover -s tests -v
python -m scripts.verify_results
python -m scripts.check_release
```

以上只使用 Python 标准库。进一步下载上游固定版本的 train 文件，可重新执行全部 2,755 条预测、核验真实答案：

```bash
python -m scripts.prepare_data
python -m scripts.verify_results --source-training-file data/raw/finqa/train.json
```

[复现说明](docs/REPRODUCE.md)记录训练环境和执行命令。训练入口默认只打印计划，添加 `--execute` 才会启动训练；完整公开训练与基准评测尚未重跑。v0.1.1 已验证权重解包、实际生成配置校验和训练来源八题的 GPU 流程，不把该小样本成绩解释为泛化或 RL 收益。

## 边界

执行正确不等于操作数证据来源正确；只有一个 SFT 种子，每题一次固定随机生成；区间未做多重比较校正。v3 final 已打开，后续扩展不能继续把它作为新方法的独立确认集。v0.1.1 权重保持原始字节，八题试跑也不替代完整基准重跑。
